# Audit: BlockAuth on branch `feature/risk-scoring-hardening`

Started 2026-11-23 from the safety snapshot `safety/pre-hardening-2026-11-23`. Every finding below was observed
by running something (a test, a tool, a request) or read in the code and then confirmed by a test; "Status" says
whether it is fixed on this branch, and which test covers it. File and line refer to the code **before** the fix
(the safety commit). Commands and outputs are in `docs/IMPLEMENTATION_LOG.md`.

Severity: **High** = can let something wrong through or break a supported deployment; **Medium** = wrong
behaviour, data loss or a hang under realistic conditions; **Low** = quality, consistency or documentation;
**Info** = checked and found correct (refuted hypothesis), recorded so it is not re-checked.
